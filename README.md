# mao-ledger

面向小学阶段孩子的零花钱记账与规划 Web 应用（纯前端）。

## 项目目标

帮助孩子以轻松、有趣、可视化的方式管理零花钱，并在家长陪伴下建立基础财商习惯：

- 建立“零花钱共识契约”
- 先做月度计划，再记录实际收支
- 通过汇总复盘形成经验
- 结合 AI 对话进行实时提醒与引导

## 技术路线（MVP）

- **架构**：纯前端 SPA（无后端）
- **存储**：IndexedDB（主存储）+ localStorage（轻量设置）
- **导入导出**：JSON 文件（手动下载 / 上传）
- **AI 接入**：
  - 由用户在本地填写 API Key（仅浏览器本地保存）
  - 前端直接调用兼容 OpenAI 接口的模型服务（如 GPT/Gemini/DeepSeek 兼容网关）
  - 提供“关闭 AI”与“清除密钥”能力
- **UI**：简洁信息结构 + 可切换主题（可爱 / 帅气 / 简约）
- **文案语言**：中文主文案 + 英文小字副文案（显示在中文下方）

## 功能范围（MVP）

1. **共识契约**
   - 家长与孩子约定：金额、发放频率、可用范围、储蓄比例等
2. **月度计划**
   - 计划分配：自己使用 / 送礼 / 储蓄 / 其他
3. **实际收支**
   - 记录流入流出，支持分类与备注
4. **汇总页面**
   - 月度计划 vs 实际对比、结余、储蓄进度
5. **AI 助手**
   - 解释当前使用情况
   - 复盘消费习惯
   - 辅助判断“是否需要花这笔钱”

## 本地浏览器试用

### 环境要求

- Node.js 18+（建议 LTS）
- npm 9+

### 启动步骤

1. 安装依赖：

   ```bash
   npm install
   ```

2. 启动本地开发服务器：

   ```bash
   npm run dev
   ```

3. 在浏览器打开终端里显示的本地地址，通常是：

   ```text
   http://localhost:5173
   ```

4. 建议按这个顺序试用：
   - 先去 **共识契约 Contract** 新建规则
   - 再去 **月度计划 Monthly Plan** 生成或编辑本月计划
   - 然后在 **收支记录 Transactions** 添加固定收入、特殊收入和支出
   - 最后在 **汇总分析 Summary** 和 **仪表盘 Dashboard** 查看结果

### 常用命令

```bash
npm run dev
npm run build
npm run preview
npm test
```

### 本地数据说明

- 数据默认保存在浏览器本地（IndexedDB / localStorage）
- 刷新页面后数据会保留
- 可在 **设置 Settings** 中导出 / 导入 JSON 备份
- 如果想完全重置本地数据，可以清除浏览器里该站点的本地存储数据
